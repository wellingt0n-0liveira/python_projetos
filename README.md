# python_projetos

Projetos práticos envolvendo Python, focados em lógica, automação, análise de dados e aplicações para o mercado de trabalho.

## Projetos

- [Calculadora](./Calculadora/README.md) – Calculadora simples em Python com operações básicas.
- [Cifra de César](./Cifra%20de%20Cesar/README.md) – Implementação da cifra de César para cifrar textos e introduzir conceitos de criptografia.
- [Dia 1 – Automações de Tarefa](./Dia%201%20Projeto%201%20Automa%C3%A7%C3%B5es%20de%20Tarefa/README.md) – Automação de cadastros em sistema web usando Python, pyautogui e dados em CSV.
- [Dia 2 – Analisando Dados com Python](./Dia%202%20Projeto%202%20Analisando%20Dados%20com%20Python/README.md) – Análise exploratória de dados de cancelamento com pandas e Jupyter, extraindo métricas e insights de negócio.
- [Dia 3 – Inteligência Artificial e Previsões](./Dia%203%20Projeto%203%20Intelig%C3%AAncia%20Artificial%20e%20Previs%C3%B5es/README.md) – Treino de modelo de Machine Learning para prever comportamento de clientes a partir de bases históricas e novos dados.
- [Gerador de Resultados – Pedra, Papel e Tesoura](./Gerador%20de%20Resultados%20pedra%20papel%20tesoura/README.md) – Simulador de Pedra, Papel e Tesoura para praticar lógica condicional e interação via linha de comando.
